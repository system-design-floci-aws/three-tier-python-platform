# Three-tier AWS network (Terraform)

A reusable wrapper around terraform-aws-modules/vpc/aws with an isolated dev root. This is a **production-oriented starter**, not a complete production deployment.

## Network

- VPC `10.0.0.0/16` in two AZs
- Two public subnets intended for a public ALB
- Two private application subnets; NAT off by default
- Two isolated database subnets and an RDS subnet group
- An internet gateway for public subnets
- No application, ALB, endpoints, RDS or security groups yet

## Before deploying

1. Configure AWS SSO or an assumed IAM role (do not put keys in `.tf`).
2. Set `allowed_account_ids` in `environments/dev/terraform.tfvars` to your actual development AWS account.
3. For collaborative deployments, provision a dedicated S3 state bucket **first** (versioning, server-side encryption, block public access, least-privilege IAM); copy `backend.tf.example` to `backend.tf`, replace its bucket, then `terraform init -reconfigure`. Do not deploy using local state for a team.
4. Confirm AZs and all subnet CIDRs. CIDR containment and overlap need additional CI validation.
5. Review network charges (especially NAT and endpoints) before enabling more features.

## Commands

```bash
cd environments/dev
terraform fmt -recursive
terraform init
terraform validate
terraform plan -out=dev.tfplan
# only after plan review / approval:
terraform apply dev.tfplan
```

Commit `.terraform.lock.hcl` generated by `init`, and review provider/module upgrade PRs. Prefer a tested exact module version in a regulated production workflow: `~> 6.0` permits all compatible 6.x updates, so change management must govern updates.

## Important behavior

- `enable_nat_gateway = false` means no general internet access from private app subnets. AWS private endpoints can provide ECR/S3/Logs/Secrets Manager connectivity later; third-party package downloads still need another controlled path.
- Database subnet routes have no configured default route through IGW or NAT. Access is still controlled with security groups and IAM configured in later modules.
- `map_public_ip_on_launch = false` does **not** make public subnets private: public subnet routing remains via IGW.
- A Terraform `check` emits warnings rather than blocking every deployment on all Terraform versions; add mandatory CI CIDR validation/policies before production.
- Do not change upstream module internals manually. Treat module upgrades and structural network changes as reviewed migrations.
